### Step 2: Fill Out the Registration Form

When you reach the download page, you'll need to complete a registration form with your information. Note that "The trial download cannot be installed on mobile devices."&#x20;

### Step 3: Choose Your Download Option

After registration, you'll be presented with two main options:

* "Pentaho EE Data Integration & Analytics installers you can install on-premises"
* "Pentaho EE Data Integration & Analytics Docker images, configured to run on AWS, Google Cloud or Azure"

Select the on-premise option.

### Step 4: Download the Software

Click the "Download" button for your chosen option. The download will provide you with "the full suite of capabilities" for a "free 30 day trial."

### Step 5: Install the Software

Installing Pentaho Data Integration (PDI) client tool is a simple three-step process that will be outlined in the installation instructions. Follow the instructions provided after download.

### Troubleshooting Download Issues

If you encounter any problems downloading:

* Try a different browser
* Clear your cache/cookies
* Disable pop-up blockers
* Try running the browser in anonymous/private mode

If using Edge browser, you may need to mark the file as 'safe' after downloading. To do this, right-click the file in the 'Downloads' area within Edge and mark it as safe.

Before installing, check that your system meets the requirements by reviewing the components reference for the current version.

If you still can't download the file after trying the above advice, contact Pentaho support at trialexperts.pentaho@hitachivantara.com and provide information about your operating system (Mac/Windows/Linux).

### After Installation
